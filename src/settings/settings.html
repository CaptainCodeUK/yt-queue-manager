Best-effort, off by default. Uses your browser's built-in sync, so it only works reliably between devices running the same browser (e.g. Chrome to Chrome, or Edge to Edge) signed into the same account with sync turned on. It won't bridge different browsers (e.g. Chrome to Vivaldi), and support varies across Chromium-based browsers — this may not work as expected.
