Best-effort, off by default. Uses your browser's built-in sync, so it only works reliably between devices running the same browser (e.g. Chrome to Chrome, or Edge to Edge) signed into the same account with sync turned on. It won't bridge different browsers (e.g. Chrome to Vivaldi), and support varies across Chromium-based browsers — this may not work as expected.

Vivaldi Notes queue sync (experimental)

Vivaldi doesn't give extensions any way to read or write Notes directly, so this is a manual relay: copy your queue, paste it into a Vivaldi Note (it'll sync to your other devices via Vivaldi Sync), then on another device copy that note's text back out and paste it in below to import it. Shown here because this browser identifies itself as Vivaldi — that check isn't foolproof.
